# 五十万卡达到90%正确有效产出：初步评估

这里的90%指30天任务保留的正确计算进度占720小时的比例，不是仅衡量是否停机。

建议以全局恢复尝试不超过120秒、全系统静默即时检出率99.9%作为有余量的候选目标。该建议依赖重执行、进程重调度、50域弹性、step恢复和60秒计算/1秒保存的组合能力成立，不能仅修改恢复时间就套用。

## 推荐方案复核（每组10,000个月任务）

| 全系统静默检出率 | 全局恢复 | 平均有效产出 | 均值95%CI半宽 | 单月达到90%的比例 |
|---|---:|---:|---:|---:|
| 99% | 120秒 | 91.91% | ±0.115个百分点 | 85.2% |
| 99.5% | 120秒 | 93.04% | ±0.084个百分点 | 92.1% |
| 99.9% | 120秒 | 94.01% | ±0.041个百分点 | 98.3% |

平均达标不等于每个月都达标；以上比例来自当前随机模型，不是生产SLA。

## 主要扫描结果

| 情景 | 平均有效产出 |
|---|---:|
| 组合 SDC0.95 全局180s | 82.71% |
| 组合 SDC0.95 全局0s | 84.68% |
| 组合 SDC0.98 全局60s | 90.64% |
| 组合 SDC0.99 全局180s | 91.19% |
| 组合 SDC95% 兜底24h | 90.92% |
| 组合 SDC95% 兜底6h | 92.76% |
| 全局 5min/4s SDC100% 0s | 88.22% |

静默检出仍为95%且兜底延迟五天时，即使全局恢复为0秒，组合仍无法达到90%。替代路径是把静默漏检兜底发现缩短到小时级：95%即时检出、六小时兜底、三分钟全局恢复的组合约为92.8%。

## 参数与边界

- 恢复时间扫描仅修改全局CKPT与亚健康恢复尝试；局部恢复180秒、进程恢复60秒、重执行5秒保持不变。
- 除特别标记外，自动恢复成功率99%，失败后额外人工120分钟；扫描中的0秒仅为数学上限情景。
- 50域弹性必须允许其他域继续产生可保留的有效进度；备用资源、同步阻塞、共因故障和收敛影响尚未计入。
- 99%/99.9%必须覆盖全系统静默事件。Core占SDC85%，仅Core内95%检出最多对应全系统80.75%覆盖。
- 基线故障比例：中断96.6%、亚健康2%、静默1.4%；万卡中断MTBF30小时。基线CKPT为300秒计算/4秒保存；组合情景为60秒计算/1秒保存。
- 亚健康恢复保留当前进度，零回滚；静默漏检回到错误前的永久干净检查点，保留此前进度。
- 参数包含用户约束与工程先验，不宣称厂商实测；置信区间只反映抽样误差。
