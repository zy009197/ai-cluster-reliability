# AI 集群可靠性评估 · 当前版本 V4

下载仓库后，在浏览器打开下面的 HTML 即可离线使用；GitHub 文件页面仅展示源码，不直接执行交互页面。

当前交互入口：**[正确有效产出改进分析.html](正确有效产出改进分析.html)**。

- [更新与模型契约](V4更新与模型契约.md)：指标、拓扑、恢复、损失账本、证据等级与未覆盖范围。
- [运行与 Shapley 说明](Shapley计算说明.md)：程序入口与归因公式。
- `可靠性场景V4.json`：本版默认场景，可在页面导入；点击刷新后应用。
- `Shapley贡献结果.json`：完整规模/组合/损失/分位数结果，绑定模型与实验摘要。
- `故障台账格式示例.json`：合成格式样例，不能当作真实故障统计。

在本目录执行：

```sh
node 计算Shapley贡献.cjs --trials 2048
node 构建评估报告.cjs
node 验证Shapley贡献.cjs
node 验证V4模型.cjs
node 验证V4结果.cjs
```

`验证V4交互.cjs` 另需 Playwright 和 Chromium，用于离线浏览器刷新、取消、导入导出及布局检查。可通过 `PLAYWRIGHT_MODULE`、`CHROMIUM_EXECUTABLE` 指定安装位置。

原 V3 的主页面、引擎、分析代码与结果已保存在 `历史版本/V3/`。其他早期报告及三类故障 HTML 为历史产物，不能与当前 V4 结果混用。V4 的 HTML 通过统一构建脚本生成，不应单独手改内嵌引擎。
